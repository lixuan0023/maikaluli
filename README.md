# 麦卡路里（MaiKaluli）

> 告诉它你的热量目标，它用麦当劳**真实菜单 + 真实营养数据 + 真实优惠券**给你配一餐——还有记忆，越用越懂你。

参赛作品：WorkBuddy 赛道 & 麦当劳程序员创意开发大赛（同步参赛）。

## 它能做什么

| 你说 | 它做 |
|---|---|
| 「午餐帮我配一顿，600 卡以内」 | 读取你的画像 → 拉门店真实菜单+营养库+可用券 → 脚本求解热量达标且最省钱的方案 |
| 「巨无霸多少卡」 | 调 `list-nutrition-foods` 返回热量和蛋白质/脂肪/碳水/钠 |
| 「记住我不吃辣，预算 40」 | 更新本地画像，下次配餐自动生效 |
| 「帮我把能领的券都领了」 | 一键领全券，临期券优先提醒 |

## 真实数据实测（2026-10-23）

以「600 千卡 / 预算 50 / 不吃辣」实测（深圳某门店，外送）：

| 方案 | 热量 | 实付 |
|---|---|---|
| 麦香鸡 + 香芋派 | 601 千卡（目标 +1） | ¥27.0 |
| 汉堡包 + 菠萝派 + 燕麦奶 | 601 千卡 | ¥45.0 |
| 麦香鱼 + 可口可乐 + 纯牛奶 | 601 千卡 | ¥46.5 |

全部使用营养库真实数据（非估算），口味禁忌生效（辣味券对应的麦辣堡被正确排除）。

## 差异化

1. **真数据**：菜单价、营养、券全部来自麦当劳 MCP 实时返回，不编造；营养库缺失的单品明确标「估」。
2. **有记忆**：画像（热量目标/口味/预算/常去门店）存本机 `~/.workbuddy/skills-data/maikaluli/profile.json`，说「我改 1800 卡了」即刻更新。画像只存本机，不上传。
3. **算法配餐**：`scripts/plan_meal.py` 枚举组合 × 逐券评估，目标是「热量贴近目标，同热量下实付最低」，不靠大模型口算。
4. **健康+省钱双达标**：配餐时自动叠券。

## 安装使用（WorkBuddy）

1. 配置麦当劳 MCP：见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。
2. 安装 Skill：下载 [maikaluli.zip](https://github.com/lixuan0023/maikaluli/releases) 或把 `skill/` 复制到 `~/.workbuddy/skills/maikaluli/`。
3. 首次使用会引导建档（热量目标/口味/预算/门店），之后说「午餐帮我配一顿」即可。
